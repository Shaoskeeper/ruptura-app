📦 Ruptura+

«Sistema web para identificação e controle de produtos em ruptura e estoque virtual em operações de supermercados.»

📖 Sobre o projeto

O Ruptura+ foi desenvolvido para solucionar um problema recorrente na operação de supermercados integrados ao iFood e outros canais de e-commerce.

Durante a operação, diversos produtos eram marcados como indisponíveis, porém a equipe não conseguia identificar rapidamente se o item realmente estava em ruptura ou se existia uma divergência entre o estoque físico e o estoque registrado no sistema (estoque virtual).

Pensando nisso, desenvolvi uma aplicação web leve, responsiva e de fácil utilização, permitindo que qualquer operador realize conferências diretamente pelo navegador, sem necessidade de instalação.

---

🎯 Objetivo

Facilitar a identificação de produtos em ruptura ou estoque virtual, agilizando a tomada de decisão da equipe operacional e reduzindo inconsistências entre o estoque físico e o sistema.

---

✨ Funcionalidades

- 📷 Leitura de código de barras utilizando a câmera do dispositivo.
- ⌨️ Digitação manual do código EAN.
- 🔍 Consulta automática da descrição do produto utilizando bases públicas.
- 📦 Cadastro da quantidade encontrada.
- 🚫 Classificação como Ruptura.
- 👻 Classificação como Estoque Virtual.
- 💾 Armazenamento local utilizando LocalStorage.
- 📊 Painel com indicadores da operação.
- 📋 Listagem e filtros por tipo e data.
- 📤 Exportação dos registros para arquivo CSV compatível com Microsoft Excel e Google Sheets.
- 📱 Interface responsiva para computadores e dispositivos móveis.
- 🌐 Funcionamento diretamente no navegador, sem necessidade de instalação.

---

🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- ZXing (Leitura de código de barras)
- Open Food Facts API
- Cosmos Bluesoft API
- LocalStorage

---

🚀 Como utilizar

1. Abra o sistema no navegador.
2. Escolha o tipo de ocorrência:
- Ruptura
- Estoque Virtual
3. Leia o código de barras utilizando a câmera ou digite o EAN.
4. Aguarde o preenchimento automático da descrição do produto.
5. Informe a quantidade encontrada.
6. Salve o registro.
7. Ao final da conferência, exporte os dados em formato CSV para análise ou correção do estoque.

---

💡 Problema resolvido

Antes da utilização da ferramenta:

- Produtos indisponíveis eram identificados manualmente.
- Havia dificuldade para localizar rapidamente produtos em estoque virtual.
- O processo consumia tempo da equipe operacional.
- O controle era descentralizado.

Com o Ruptura+, a equipe consegue:

- Identificar rapidamente o produto através do código EAN.
- Registrar ocorrências em poucos segundos.
- Diferenciar ruptura física de estoque virtual.
- Gerar um inventário para conferência e correção do sistema.
- Apoiar a operação do e-commerce da loja com maior agilidade.
